# Задание 2

 - Разделите систему на домены:

    Для разделения системы на домены используется принцип Data Mesh – каждый бизнес-юнит владеет своими данными как продуктом, а Data LakeHouse становится лишь агрегатором для кросс-доменной аналитики. Для разделения данных используется система DataHub, которая автоматически присваивает данным необходимые метаданные, которые можно использовать для разграничения прав доступа для пользователей из разных доменов.

    Разделение на домены:
     - Домен медицинских данных - управляет медицинскими картами, историями болезней, исследований.
     - Домен финансовых данных - управляет счетами, финансовой историей, кредитами, финансовой отчетностью.
     - Домен клиентских данных - управляет персональными данными клиентов.
     - Домен внутренних данных - управляет персоналом больницы, инвентаризация.
     - Домен машинного обучения - управляет данныи для обучения машинных моделей.
     - Домен внешних сервисов - управляет данными фармацевтических компаний и производителей электроники.

 - Аргументируйте логику разделения на домены.

   Преимущества для компании:

  - Независимость разработки: разбиение на отдельные сервисы позволит вести разработку разных систем параллельно.
  - Упрощение масштабирования: можно горизонтально масштабировать только проблемные сервисы.
  - Отсутствие единой точки отказа: использование раздельных БД устраняет единую точку отказа в виде БД MS SQL.
  - Ускорение обработки аналитики данных: использование метаданных позволит отдельным командам обрабатывать аналитические данные раздельно и ускорит формирование отчетов.
  - Права доступа к данным: использование метаданных позволит ограничить права доступа пользователям к данным
  - Соответствие законодательству: позволит управлять хранением и передачей персональных и медицинских. Например, обезличивать или удалять по запросу чувствительные данные.
  - Интеграция новых бизнесов: разбиение на домены позволит легко добавлять новые домены или расширять старые.
