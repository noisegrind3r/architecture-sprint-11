 - Обоснуйте изменения:

   T1, T2 - формирование архитектурного решения необходимо для дальнейшей детализации процесса переход.
   T3, T4 - Перенос данных и бизнес-логики со старой БД позволит решить проблемы с производительностью, надежностью (единая точка отказа) и повысит TimeToMarket (независимые команды разработчиков).
   T5 - Повысит автономность сервисов и позволит проще интегрировать новые системы (фармацевтические компании, производитель электроники).
   T6 - Замена DWH на Data LakeHouse позволить упростить работу с данными, повысит производительность, ускорит получение и точность аналитики.
   T7 - Настройка захвата данных в Debezium необходима для сбора данные в систему Data LakeHouse.
   T8 - Настройка ETL для данных в Airflow позволит привести данные к необходимому виду для упрощения сбора аналитики.
   T9, T10 - Автоматическое определение метаданных позволит настроить права доступа на данные и разграничить их согласно доменной модели. Упростит хранение и передачу данных для соответствия законодательству.
   T11 - Настройка BI-отчетов необходима для получения требуемых данных для работы аналитиков.
   T12 - Доработка AI сервисов необходима для взаимодействия ИИ-сервисов с новой системой Data LakeHouse.
   T13 - Перенос инфраструктуры сервисов в облако позволит упростить масштабирование что повысит производительность системы.
   T14 - Вывод старой системы DWH из эксплуатации после тестирования позволит сократить затраты на инфраструктуру.
